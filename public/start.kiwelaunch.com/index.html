Three steps

  1. /ideate — use your Design Context and attachments to plan the website. Review the brief.
  2. /preview — approve that brief and get a complete raw HTML, CSS and JavaScript preview.
  3. /seam — happy with the preview? Prepare the same design with Seam variables, attributes and explicit native Bricks intent. Import through the Seam compiler with Framework enabled.

All 9 commands

  • /ideate — Inspect attachments and resolve whether an existing design is final, enhancement-authorized or redesign-authorized before SiteGraph or creative work; after any requested evidence arrives, emit and pause on the grounded usage brief. Production output may not retain placeholders when sufficient SiteGraph or approved-source context exists, and must fail closed on runtime errors or incomplete semantic closure. Inert data-seam-anchor stitches plus the closed SEAM Map express conversion intent without influencing design. Attachments never grant approval and /ideate alone never grants redesign permission.
  • /preview — This command approves the current usage brief and generates raw preview source. Preserve the established design authority; no real form delivery, site mutation or deployment.
  • /seam — Accept the current preview for Framework source preparation only. Use relevant complete vocabulary/tokens/attributes and explicit native loop/interaction/condition intent; preserve art direction. Only seam.kiwe produces Bricks JSON. No live approval.
  • /convert /bricks — Fallback binding-only handoff for accepted pre-existing source that did not originate with a strict SEAM Map. Use sourcePolicy immutable, exact per-file targets, explicit field slots, source guards and repeat prototypes. Never rewrite source or emit Bricks JSON.
  • /audit — Read only. Never modify the submitted artifact.
  • /accessibility — Audit only. Use /fix to create a changed artifact.
  • /fix — Apply only proven findings and preserve art direction, content and behavior.
  • /redo — Discard the failed output as authority; return to the last accepted artifact.
  • /library — Read-only complete public authoring reference. Fetch relevant resources without repository crawling or inventing site-specific capabilities.

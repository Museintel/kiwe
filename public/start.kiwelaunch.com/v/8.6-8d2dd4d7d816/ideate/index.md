# /ideate

SEAM contract: 8.6

Inspect attachments and resolve whether an existing design is final, enhancement-authorized or redesign-authorized before SiteGraph or creative work; then pause on the grounded usage brief. /ideate alone never grants redesign permission.

## Requires
- project request or inspectable attachments; explicit source authority for an existing design; SiteGraph only when preflight proves it is required
- user says proceed after reviewing the usage brief

## Outputs
- source-authority decision
- Design Context coverage report before modification
- page-relevant Design Context and Design Content usage brief
- ideate/kiwe-ideate-discovery.json
- complete raw HTML/CSS/JS project after approval
- asset manifest

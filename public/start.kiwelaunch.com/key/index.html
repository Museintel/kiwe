Accounts

WhatsApp number → scan → account.

  1. Enter an international WhatsApp number.
  2. Scan from that same number using Linked devices.
  3. The paired connection becomes the account primary.

Login

A six-digit, five-minute code travels from the account’s own connection to its registered number. Codes are one-time, attempt-limited, rate-limited, and stored only as hashes.

Offline recovery

Reconnect your Key shows a fresh QR. Only the already-registered number can complete it. Sites and signing credentials are preserved.

Connections

Primary by default. Client-specific by choice.

account_primary inherits the owner number. dedicated uses an isolated client connection.

Pairing a client number never interrupts the working primary route. The switch occurs only after the scan succeeds. Replacement affects one website; returning to primary closes and clears only that dedicated association.

Network Oversight

The master sees each account, website, actual serving number, connection mode, status, and last transaction. Full numbers are restricted to the master for abuse response.

Kiwe integration

Three values connect WordPress.

  • Gateway: https://key.kiwelaunch.com/v1/otp
  • Tenant key ID: generated per website
  • Signing secret: shown once per website

Store the secret in Kiwe Secret Store. Kiwe signs the exact JSON body using X-Kiwe-Key-* headers. The gateway validates tenant, HTTPS origin, timestamp, nonce, signature, purpose, status, and limits.

Kiwe 8.0.0-rc.45+ migrates the exact old hosted gateway automatically while preserving WordPress accounts, factors, trusted devices, tenant IDs, and secrets.

Security

Bounded transport, not arbitrary messaging.

  • AES-256-GCM for phone numbers and tenant secrets.
  • Hashes for lookup, sessions, pairing, reconnect, and OTP challenges.
  • Isolated HMAC credentials and approved origin per website.
  • Separate persistent state directories for dedicated connections.
  • OTP bodies are never retained or returned.
  • Suspension revokes sessions and delivery.

The pinned Baileys transport may disconnect; Key.kiwe exposes honest health, controlled QR repair, and deterministic email-fallback signalling instead of promising impossible delivery guarantees.

API

Small public surface.

  • POST /v1/otp — requested authentication code.
  • POST /v1/message — consented allowlisted notification.
  • POST /v1/event — bounded delivery/fallback outcome.
  • GET /health — non-sensitive readiness.

New integrations use X-Kiwe-Key-Id, timestamp, nonce, and signature. Temporary old-header aliases exist only for controlled rollout compatibility.

Operations

Recovery stays scoped.

HTTP 200 from /health means the transport is open. HTTP 503 means WordPress should use email fallback or the owner should reconnect.

  1. Pause the affected site/account.
  2. Record its origin, serving number, mode, state, and last transaction.
  3. Rotate only the affected secret/connection.
  4. Verify origin and recent signed traffic.
  5. Restore only after the expected number pairs.

Production state lives outside deployment roots. Source archives exclude secrets, runtime configuration, linked-device state, and node_modules.

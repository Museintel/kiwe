# Compiler fixtures

`landing-hero` and `editorial-card` are deliberately unrelated synthetic captures. They prevent the compiler skeleton from learning one supplied homepage's structure.

`golden/national-chikki` preserves the user's supplied homepage byte-for-byte as the first real regression artifact. Its compact M2 evidence manifest records the canonical seven-viewport rendered capture, screenshot and package hashes, geometry summary, native/residual metrics, and clean validation results. The 12 MB raw capture and screenshots remain content-addressed external artifacts rather than repository ballast.

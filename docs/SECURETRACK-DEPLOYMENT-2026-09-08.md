## Native findings and resulting correction

The [RC69 investigation](SECURETRACK-SCHEMA-RC69-2026-09-08.md) reproduced repeated table alterations. Native acceptance subsequently found one more defect in its new guard: WordPress dbDelta deliberately probes missing tables using DESCRIBE. A missing-table metadata error is expected during initial creation. RC70 records whether the preceding query was a write and stops after failed writes; it permits metadata discovery and still requires final native readiness and version readback. Failure and connection-ownership guards remain in place. The stored schema is unchanged.

Actual Hostinger acceptance used WordPress 7.1, PHP 8.2.33 and MariaDB 11.8.8, with the candidate loaded from a private directory outside public_html. Installed lab files were not swapped. Normal plugins were excluded only in the test process because a plugin interrupted the first CLI bootstrap. The lab normally has SecureTrack disabled, so the fixture explicitly loads it after switching to isolated options and a random test-table prefix. No provider requests or messages are sent.

The final native fixture passed 18 checks: exact candidate and complete package inventory; isolated options/cache; zero DDL during ordinary boot/helpers and unavailable logging; creation of ten new tables; verified readiness/version; non-autoloaded status; cooldown; zero DDL on a second matching-schema maintenance; real connection-lock release and contention. Connection-close verification permits up to 500ms for the server to acknowledge the closed socket. Every test table was removed. Earlier failed receipts remain historical, including the fresh-schema guard regression and a too-immediate connection-close assertion.

The local coordinator suite passes 25 boundary cases plus one explicit CLI case. It covers failed writes, expected metadata failures, unavailable storage, nonce/role/method restrictions, lock loss, cooldown, and failure cleanup. Real SQL write-error injection/reconnection during a DDL operation remains outside native acceptance; those denial paths have synthetic boundary coverage.

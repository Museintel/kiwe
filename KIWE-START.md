## The command-only journey

Supply the project brief, assets and safe Design Context once. `/ideate` prepares the grounded usage brief; `/preview` approves that brief and produces raw browser-runnable HTML/CSS/JS; when happy with that identified preview, `/seam` prepares the same design with relevant Seam attributes, tokens and variables plus explicit native Bricks intent. It preserves the original and produces a separate source copy. Upload that copy to seam.kiwe with Framework enabled. No command here grants site deployment permission. Missing facts still require an answer; commands never invent business information.

Browse the [complete versioned reference library](https://start.kiwelaunch.com/library/) or its [machine index](https://start.kiwelaunch.com/library/catalog.json). It includes all public source resources in the declared families and exact JSON pointers/hashes. Site-created tags and target-calibrated Bricks capabilities additionally come from the current site. Registered, supported and executed are different evidence levels. Use only the entries the design needs; completeness is not a command to add everything to every page.

Visual quality and the accepted design take priority. Use Seam where it helps; preserve distinctive art direction, scoped values and script-owned variables. Supply real source assets with provenance. AI does not invent Media/Bricks IDs or the final Profile/import plan: the deterministic compiler derives the dependency ZIP from actual bytes. Kiwe's separate target review handles native Media, compatible shared styles and draft templates; package hashes do not prove a successful import or grant live approval.

SEAM has nine commands:

- [`/ideate`](https://start.kiwelaunch.com/contexts/ideate.md) ([GitHub context mirror](https://github.com/Museintel/kiwe/blob/main/kiwe-ai-toolkit/contexts/ideate.md)) — inspect the supplied project, establish whether its design is final, enhancement-authorized or redesign-authorized, classify whether SiteGraph is required, report Design Context coverage, then create or refine raw HTML/CSS/JS without imposing a house style. Its invisible stitches and closed SEAM Map carry conversion meaning without influencing the design.
- [`/preview`](https://start.kiwelaunch.com/contexts/preview.md) — approve the current usage brief and build the raw preview, with actual browser checks.
- [`/seam`](https://start.kiwelaunch.com/contexts/seam.md) — accept the current preview for design-preserving Framework source and exact dynamic/native intent.
- [`/library`](https://start.kiwelaunch.com/contexts/library.md) — consult the complete source-bound reference without changing anything.
- [`/convert /bricks`](https://start.kiwelaunch.com/contexts/convert-bricks.md) ([GitHub context mirror](https://github.com/Museintel/kiwe/blob/main/kiwe-ai-toolkit/contexts/convert-bricks.md)) — for an accepted pre-existing project without a SEAM Map, return only a guarded binding graph and report while keeping source unchanged. Add `/dynamictags` or `/queryloop` to narrow the pass. Only seam.kiwe emits Bricks JSON.
- [`/audit`](https://start.kiwelaunch.com/contexts/audit.md) ([GitHub context mirror](https://github.com/Museintel/kiwe/blob/main/kiwe-ai-toolkit/contexts/audit.md)) — inspect an artifact without changing it.
- [`/accessibility`](https://start.kiwelaunch.com/contexts/accessibility.md) ([GitHub context mirror](https://github.com/Museintel/kiwe/blob/main/kiwe-ai-toolkit/contexts/accessibility.md)) — audit accessibility, responsive geometry and light/dark presentation.
- [`/fix`](https://start.kiwelaunch.com/contexts/accessibility.md) ([GitHub context mirror](https://github.com/Museintel/kiwe/blob/main/kiwe-ai-toolkit/contexts/accessibility.md)) — correct proven audit findings while preserving the accepted design.
- [`/redo`](https://start.kiwelaunch.com/contexts/audit.md) ([GitHub context mirror](https://github.com/Museintel/kiwe/blob/main/kiwe-ai-toolkit/contexts/audit.md)) — replace a failed output from the last accepted artifact and failure evidence.

SiteGraph and its embedded Design Context are attached or safely connected project inputs. They are not commands. For an existing supplied design, `/ideate` first establishes source authority: final/approved, enhancement-authorized, or redesign-authorized. The command itself never grants redesign permission. If the user's intent is not explicit, the AI asks that one question and stops. It then classifies SiteGraph as required, beneficial or not needed. If required evidence is absent, it asks for one safe read-only handoff. Attaching or connecting that requested evidence never counts as `proceed`: the AI must next report Design Context coverage and a concise, page-relevant Design Context and Design Content usage brief, stop, and wait for `/preview` or the user's explicit `proceed` before changing or creating files. After approval, `/ideate` adds inert `data-seam-anchor` stitches and `seam/seam-map.json`. When SiteGraph is cited it also carries the unchanged `seam/site-graph.json`; hashes, revisions, JSON pointers, tags, query types, modules, source guards and closure are verified. Unmarked content means preserve static source. A missing or stale proof stops conversion rather than triggering inference. `/seam` explicitly prepares the accepted preview as Framework source; the `seam.kiwe` compiler still performs native conversion with Framework enabled. Browser AI never emits production Bricks JSON; only the `seam.kiwe` application does.

Unknown commands, aliases and unsupported modifiers must be rejected.

Public Design Context facts use the attached `dynamicBindings` catalogue. The visual preview retains real values and exact inert `data-seam-field`/`data-seam-slot` markers alongside `data-seam-anchor`; the closed field stitch cites the same binding, native tag and guarded slot. Never manufacture private, planning-only or unknown future bindings.
